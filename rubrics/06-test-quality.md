# Test Quality (0–10)

Coverage, tier classification, and assertion quality.

| Score | Observable Evidence |
|---|---|
| 0 | No tests provided when required by the task. |
| 2 | Tests exist but assert nothing meaningful, or test the wrong thing entirely. |
| 4 | Happy path tested. Correct tier (unit tests for pure logic). No error paths. |
| 6 | Happy path and some error paths tested. Clear arrange-act-assert pattern. Correct tier classification. |
| 8 | Good coverage across happy path, error paths, and edge cases. Test names describe the behavior being verified. Correct test tier for each scenario. |
| 10 | Thorough: happy path, error paths, boundary values, serialization round-trips. Tests serve as documentation of expected behavior. |
